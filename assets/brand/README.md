# Code.Hub brand references

Captured from the public Code.Hub homepage on 2026-11-10 for the independent
CodeHub RAG portfolio demo. These assets remain Code.Hub's branding; this project
does not claim ownership or official affiliation.

- `codehub.svg`: original header logo, preserved without modification.
  Source: https://media.codehub.gr/codehub/2026/04/09112701/codehub.svg
- `tokens.json`: the site's own `ds-color` WordPress color presets, extracted from
  the homepage's inline CSS, plus provenance and the observed Noto Sans font family.

The palette includes Electric Orange `#f15b40`, Space Purple `#1d1036`, and the
original shade scales. These are source values, not approximate colors chosen
from a screenshot. A UI implementation still needs contrast and responsive-layout
checks; the current milestone does not implement the chat interface.

Homepage source: https://codehub.gr/
